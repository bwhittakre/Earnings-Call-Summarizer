Goal: an earnings cycle that needs manual intervention only when a NEW company is onboarded. On completing a call, look up the next earnings date from Quartr, re-verify it at T-7, run the quant check a couple of hours before, run the model at the call, repeat.

Four phases:
1. Unblock monitoring -- separate monitoring eligibility from the research book, so onboarding always registers a name in the monitored universe. (done)
2. Close the Quartr loop -- populate the watchlist from the monitored universe and get earnings events published as manifests. (in progress)
3. Make the cycle self-perpetuating -- schedule next quarter on COMPLETE, re-verify at T-7, and stop dropping rescheduled calls. (3a done)
4. Per-sector Rank IC -- namespaced output dirs, sector iteration in research_regen, sector selector in the dashboard. Chosen over one large book because Rank IC is expected to expand across many sectors.

Context: forensic review of the live monitor DB found that of 8 events processed in 5 weeks, 7 were manual_override=1 and only OPAL armed automatically. The automated cycle had effectively never run.
