Design decided 2026-09-03. Plan file: desk_autopilot_build_f961a3b2.plan.md.

## What it does
Makes the claims-desk seed pull and promise tracking fully autonomous once triggered for a ticker. Proposals that clear a deterministic bar (verbatim excerpt, passes validate_catalog_tree, not a duplicate sentence) are auto-inserted as provisional trees/verdicts. Books, regime analytics and review surfaces rebuild automatically. Budget cap $1/ticker, kill switch DESK_AUTOPILOT=0. NVDA gold stays hands-off.

## Key decisions
- Provisional tier: verbatim only (not confidence-gated). 298/310 seeds and 28/30 verdicts insert on first pass. Non-verbatim go to Re-cite queue.
- Dedup = sentence containment (mirrors excerpt_covered), never topic overlap. Same objects with different clock = distinct trees (verified on 20 same-object pairs in current proposals).
- Calibration from workbook: Accepts → confirmed, Rejects → tombstones + negatives block, acceptance rates by bucket/confidence reported in ledger.
- Materiality field: seed.materiality in {high, medium, low} + materiality_rationale. Assigned by existing seed LLM call. Deterministic fallback infer_materiality from bucket+numeric+clock. Weights 3/2/1. Two derived rates: material_only (headline) and weighted. Existing unweighted rate unchanged.
- Blanket review decision (user): all high-confidence seeds accepted (provenance user_blanket_2026-09-03), mediums → provisional, 28 verbatim verdicts → provisional, 14 non-verbatim → Re-cite queue.

## Architecture
- scripts/_desk_catalog_overlay.py: data/desk_catalog_overlay/{ops,hc}.json with trees, nodes, tombstones
- scripts/_desk_trees_v2.py: transcript-sourced nodes (delivery_basis=transcript), materiality field + rate variants, MATERIALITY_WEIGHTS
- scripts/_desk_trees_v2_ops.py / _hc.py: merge overlay trees+nodes
- scripts/_desk_autopilot.py: run_for_ticker(T, P, budget_usd, dry_run), --all, --from-existing-candidates, --dry-run, ledger
- scripts/_desk_seed_batch.py: factor _process_ticker → propose_seeds(ticker, rows, client)
- scripts/_desk_terminal_candidates.py: expose score_ticker()
- scripts/_desk_regimes_stub.py: provisional CEO entry from transcript roster
- scripts/_desk_review_sheet.py: Status + Materiality columns
- scripts/_desk_review_apply.py: Accept→confirmed, Reject→tombstone+negatives, Re-cite→tombstone-until-recited
- Roz hook and AVGO scoring are the next two steps after this build.
